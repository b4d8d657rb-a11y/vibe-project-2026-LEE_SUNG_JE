[두번째, 세번째 파트 프롬프트]
- 첨부 :
(1) 데스크탑 화면
(2) 태블릿 화면
(3) 모바일 화면
- 프롬프트 :
첫번째 페이지와 동일한 전체 화면을 채우는 박스를 만들고 제공한 화면과 같이 main>section을 구성하여
두번째, 세번째 페이지를 생성한다.
상단 메뉴등 고정요소는 그대로 두고
별도의 박스로 구성된 새로운 요소만 구현한다.
올린 이미지를 분석하여 정확한 요구사항을 반영한다.

[ 상단메뉴 수정사항 ]
1. 클래스가 header__navigation인
메뉴파트가 왼쪽에 가있어. 이것을 정중앙에 오도록 수정해.
또한 전체 상단메뉴 파트에
배경색으로 위에서 아랫방향으로 검정색에서
투명색으로 그라데이션 0.2투명도로 적용해.

[ 숏츠 파트 구현 ]
- 원본 사이트에서 숏츠 영상 정보 가져오기
-> json파일로 뽑아내기
(1) 태그를 분석기에서 복사한다.
(2) LLM AI에 아래 프롬프트를 넣고 붙여 넣는다.
"아래 태그의 데이터를 json으로 뽑아줘. 단, 태그정보는 제외해."
- 추출한 json파일로 부터 페이지 디자인 코딩시 적용하도록 한다.
