[두번째, 세번째 파트 프롬프트]
- 첨부 :
(1) 데스크탑 화면
(2) 태블릿 화면
(3) 모바일 화면
- 프롬프트 :
첫번째 페이지와 동일한 전체 화면을 채우는 박스를 만들고 제공한 화면과 같이 main>section을 구성하여
두번째, 세번째 페이지를 생성한다.
상단 메뉴등 고정요소는 그대로 두고
별도의 박스로 구성된 새로운 요소만 구현한다.
올린 이미지를 분석하여 정확한 요구사항을 반영한다.

[ 상단메뉴 수정사항 ]
1. 클래스가 header__navigation인
메뉴파트가 왼쪽에 가있어. 이것을 정중앙에 오도록 수정해.
또한 전체 상단메뉴 파트에
배경색으로 위에서 아랫방향으로 검정색에서
투명색으로 그라데이션 0.2투명도로 적용해.

[ 숏츠 파트 구현 ]
- 원본 사이트에서 숏츠 영상 정보 가져오기
-> json파일로 뽑아내기
(1) 태그를 분석기에서 복사한다.
(2) LLM AI에 아래 프롬프트를 넣고 붙여 넣는다.
"아래 태그의 데이터를 json으로 뽑아줘. 단, 태그정보는 제외해."
- 추출한 json파일로 부터 페이지 디자인 코딩시 적용하도록 한다.

- 첨부 : 데스크탑, 모바일 화면덤프
- 프롬프트:
첨부한 화면과 같은 디자인의 구성을 구현하려고해.
상단메뉴는 동일하지만 화이트톤으로 모두 반전 디자인으로 변경해
리스트의 정보는 json에서 읽어서 적용해.

[ 적용후 수정프롬프트 ]
1.현재 한페이지별 스크롤 적용중이야. 세번째 페이지 하단으로 내려가면 자연스러운 일반 스크롤로 변경해야해. 
다시 세번째 페이지로 이동시엔 자동스크롤로 다시 돌아가야해.

2.상단 메뉴가 1,2,3 페이지에서는 원래 스타일로 보이고
3페이지 하단일때 흰색반전 디자인이 적용되야해.
3페이지 하단에서 위로 스크롤 하면 2칸올라가서 2페이지가 보이는 버그가 있어. 수정해.
