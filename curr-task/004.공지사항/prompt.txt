[ 공지사항 게시판 생성 프롬프트 ]
-첨부: 게시판 각화면(4가지)
-프롬프트:
첨부된 화면과 동일하게 공지사항 게시판을 만들거야.
DB없이 로컬스토리지로 개발할거야.
개발후 파이어베이스 DB로 마이그레이션 할 예정이야.
따라서 localstorage_to_firebase_guidelines.md 파일 지침에 따라 개발 구현해야해.

- 프롬프트(수정:클로드)

첨부한 4개 화면(목록·상세·글쓰기·글수정)과 동일하게 Nothing 지원센터 공지사항 게시판을 만들어줘.

[개발 방식]
- DB 없이 localStorage로 개발하고, 이후 Firebase DB로 마이그레이션할 예정이야.
- 반드시 localstorage_to_firebase_guidelines.md 지침을 따라 구현해줘.

[구현 범위]
- 목록: 번호·제목·등록일·조회수, 공지 고정 뱃지, 카테고리 필터, 제목 검색, 페이지네이션, 글쓰기 버튼
- 상세: 목록으로, 제목·등록일, 본문, 이전글/다음글, 조회수 증가
- 글쓰기 / 글수정: 필수값 검증(제목·내용), 취소·등록/수정 동작
- 삭제 기능 포함

[화면 불일치 처리]
- 글쓰기와 글수정 모두 카테고리 + 제목 + 내용 + 첨부파일(선택, 최대 10MB)로 통일해줘.

[초기 데이터]
- 목록 화면의 7개 게시글을 시드 데이터로 넣어줘. (localStorage가 비어 있을 때만 1회 주입)
- 페이지당 게시글 수는 5개로 설정해줘.

[결과물]
- 화면과 최대한 동일한 디자인으로 구현
- 마이그레이션 시 교체할 부분이 한 곳에 모이도록 구조화


[ 공지사항 구현후 연계 수정하기 ]
- 공지사항 게시글 중 상위 3개 게시물을 별도의 박스로 구성하여 사이트 상단에 고정하고 한줄 출력하기.
내용은 3개의 게시물이 순서대로 넘어감 (멈춤,플레이,닫기버튼 포함)
