첨부한 이미지 2장은 순서대로 데스크탑과 모바일 화면입니다. 
두 이미지를 분석하여 레이아웃, 요소 배치, 크기, 간격, 타이포그래피를 최대한 유사하게 구현해 주세요.
실제로 사용된 이미지는 images/used 폴더에 있는 이미지를 사용해주세요.

### 1. 전체 구조
- 화면 최상단에 위치하는 풀스크린 히어로 섹션.
- 전체 영역은 배경 이미지가 적용된 하나의 컨테이너로 구성.
- 배경에는 어두운 블랙 톤과 일정한 간격의 작은 도트 패턴이 표현됨.
- 제품 이미지는 히어로 중앙에 크게 배치하며, 배경과 자연스럽게 겹쳐 보이도록 구성.
- 텍스트 영역과 CTA 버튼은 제품 이미지 위에 레이어 형태로 배치.
- 텍스트는 왼쪽 정렬을 기본으로 구성.

### 2. 고정 UI 요소
- 상단 중앙에 가로형 네비게이션 바 배치.
- 네비게이션 바는 스크롤과 관계없이 항상 화면 상단에 고정 (position: fixed).
- 좌측에는 햄버거 메뉴, 중앙에는 로고 배치.
- 별도의 인디케이터 메뉴 역시 화면에 고정하여 스크롤 시에도 위치 유지.
- 고정 요소는 히어로 이미지 및 콘텐츠보다 높은 z-index 적용.

### 3. 반응형 레이아웃
데스크탑을 기본 레이아웃으로 구현하고, 태블릿과 모바일 순서로 미디어쿼리를 적용.

**Desktop (1025px 이상)**
- 상단 네비게이션은 화면 중앙에 배치하고 적절한 최대 너비 설정.
- 제품 이미지는 중앙에 크게 배치.
- 텍스트는 왼쪽 영역에 배치.
- 텍스트, 제품 이미지, CTA가 서로 겹칠 수 있는 레이어 구조 적용.
- 넓은 화면에 맞춰 콘텐츠 여백과 크기 확보.

**Tablet (1024px 이하)**
- 데스크탑 레이아웃을 기반으로 요소 크기와 간격 조정.
- 네비게이션 너비 및 제품 이미지 크기 축소.
- 텍스트와 제품 이미지의 상대적인 위치 재조정.
- 화면이 좁아짐에 따라 콘텐츠가 자연스럽게 중앙에 모이도록 구성.
- 데스크탑의 넓은 여백을 축소.

**Mobile (767px 이하)**
- 데스크탑 및 태블릿과 다른 별도의 모바일 레이아웃 적용.
- 네비게이션 바는 화면 좌우에 일정한 여백을 두고 배치.
- 제품 이미지는 화면 중앙에 배치하고 모바일 화면에 맞게 크기 조절.
- 텍스트는 제품 이미지와 겹치는 중앙 콘텐츠 영역에 배치하고 줄바꿈 및 글자 크기 최적화.
- CTA 버튼은 텍스트 아래에 배치.
- 좌우 여백을 충분히 확보하고 가로 스크롤이 발생하지 않도록 처리.

### 4. CSS 구현 규칙
- Desktop 스타일을 기본값으로 작성.
- `@media (max-width: 1024px)`에서 태블릿 스타일 적용.
- `@media (max-width: 767px)`에서 모바일 스타일 적용.
- 반드시 Desktop → Tablet → Mobile 순서로 CSS를 작성하여 작은 화면에서 기존 스타일을 단계적으로 덮어쓰도록 구성.
- 단순히 전체 요소를 축소하는 방식이 아니라, 브레이크포인트에 따라 위치, 정렬, 크기, 레이어 구조가 변경되는 반응형 레이아웃으로 구현.
- 상단 네비게이션과 인디케이터는 반응형 전 구간에서 고정 상태 유지.
- 배경 이미지와 제품 이미지의 비율이 깨지지 않도록 `object-fit: contain` 또는 `background-size`를 적절히 활용.
- 이미지와 텍스트의 겹침은 absolute positioning 또는 grid 기반 레이어 구조로 구현.

### 5. 전체 메뉴 오버레이 (Full Screen Navigation)

**메뉴 실행**
- 기본 상태에서는 전체 메뉴가 숨겨져 있음.
- 히어로 섹션 상단의 햄버거 버튼 클릭 시 전체 화면 메뉴가 활성화됨.
- 메뉴는 화면 최상단에서 아래 방향으로 슬라이딩되며 등장.
- 화면 전체를 덮는 Full Screen Overlay 형태로 구현.
- 메뉴가 열리면 메뉴 영역을 제외한 기존 페이지 배경은 Backdrop Blur 처리.
- 메뉴가 열린 동안 배경 페이지의 스크롤은 잠금 처리.

**메뉴 디자인 및 레이아웃**
- 전체 메뉴 배경은 밝은 라이트 그레이 톤.
- 화면 전체 너비와 높이를 차지하는 레이아웃.
- 상단에는 X 닫기 버튼을 좌측에 배치하고 중앙에는 브랜드 로고 배치.
- 중앙 영역에는 주요 카테고리 메뉴를 세로 방향으로 배치하고 중앙 정렬.
- 메뉴 항목 간 충분한 간격 확보.
- 중앙 메뉴 하단에는 브랜드 로고 및 슬로건 배치.
- 화면 하단에는 ACCOUNT, 지원, COMMUNITY, 회사 소개 등 보조 메뉴 배치.
- 화면 크기에 따라 메뉴의 폰트 크기와 간격을 반응형으로 조절.
- 메뉴 박스에 라운드 처리.

**메뉴 닫기**
- 좌측 상단 X 버튼 클릭 시 메뉴가 닫힘.
- 메뉴는 화면 하단 방향으로 이동하는 것이 아니라, 아래에서 위로 올라가며 화면 상단 방향으로 사라지는 슬라이드 아웃 애니메이션 적용.
- 닫힌 후 기존 히어로 섹션과 배경 Blur 효과를 원래 상태로 복원.
- 햄버거 버튼과 X 버튼은 메뉴 상태에 따라 서로 전환.

**애니메이션 및 기술 구현**
- CSS Transform의 `translateY()`와 Transition 또는 Framer Motion을 활용.
- 메뉴 등장: `translateY(-100%) → translateY(0)`.
- 메뉴 퇴장: `translateY(0) → translateY(-100%)`.
- 애니메이션은 부드러운 Ease In Out 적용.
- 메뉴와 배경 Blur 레이어는 독립적으로 관리.
- 메뉴 Overlay는 `position: fixed; inset: 0`으로 구현하고 높은 z-index 적용.
- 메뉴 열림/닫힘 상태는 React State로 관리.
- 메뉴가 열린 상태에서 ESC 키를 눌러도 닫히도록 구현.
- 닫기 애니메이션이 완료된 후 Overlay를 비활성화하여 클릭 이벤트가 배경에 정상 전달되도록 처리.
- `prefers-reduced-motion`을 고려하여 애니메이션 접근성 지원.
